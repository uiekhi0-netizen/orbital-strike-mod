# Orbital Strike 1.0.0 (Minecraft 1.21.1)

มอด Fabric สำหรับ Minecraft 1.21.1 เพิ่มคำสั่งอาวุธถล่มทลายจากวงโคจร (Orbital Weaponry)

## 📌 ความสามารถของมอด
1. **คำสั่งหลัก:**
   - `/orbital nuke give [จำนวน] [ring]`
     - รับไอเทม **Nuke Shot (เบ็ดตกปลาชนิดพิเศษ)**
     - เมื่อคลิกขวาใช้งาน เบ็ดจะแตกทันที และเสก TNT ระเบิดล้อมรอบเป้าหมายที่เล็งเป็นรัศมีวงกลม 10 วง (ซ้อนกัน)
   - `/orbital stab give [จำนวน] [ring]`
     - รับไอเทม **Stab Shot (เบ็ดตกปลาแท่งเจาะ)**
     - เมื่อคลิกขวาใช้งาน เบ็ดจะแตกทันที และสั่งระเบิดเป็นแนวเสาแท่งเจาะลึกลงไปตั้งแต่ระดับความสูง **Y=120 ถึง Y=-58**

## 🚀 วิธีการแปลงเป็นไฟล์ .jar อัตโนมัติด้วย GitHub.com (GitHub Actions)

คุณไม่จำเป็นต้องลงโปรแกรมเขียนโค้ดในคอมพิวเตอร์ของคุณ สามารถให้ GitHub ประกอบและแปลงไฟล์ออกมาเป็น `.jar` ให้ฟรีได้ทันทีตามขั้นตอนนี้:

### ขั้นตอนที่ 1: สร้าง Repository บน GitHub
1. ล็อกอินเข้าเว็บ [github.com](https://github.com)
2. คลิกปุ่ม **New** (หรือเครื่องหมาย `+` ขวาบน -> *New repository*)
3. ตั้งชื่อ Repository เช่น `orbital-strike-mod`
4. เลือกเป็น **Public** หรือ **Private** ก็ได้ จากนั้นกด **Create repository**

### ขั้นตอนที่ 2: อัปโหลดไฟล์โปรเจกต์
1. แตกไฟล์ zip นี้ลงในเครื่อง
2. บนหน้า GitHub ให้กดปุ่ม **uploading an existing file**
3. ลากโฟลเดอร์และไฟล์ทั้งหมดในโปรเจกต์นี้เข้าไป:
   - โฟลเดอร์ `.github/`
   - โฟลเดอร์ `src/`
   - ไฟล์ `build.gradle`, `gradle.properties`, `settings.gradle`, `README.md`
4. กด **Commit changes**

### ขั้นตอนที่ 3: รอ GitHub Actions รัน และดาวน์โหลดไฟล์ .jar
1. ไปที่แท็บ **Actions** ด้านบนของ GitHub Repository ของคุณ
2. จะเห็นเวิร์กโฟลว์ชื่อ **Build Orbital Strike Mod (.jar)** กำลังรันอยู่ (เป็นรูปจุดหมุนสีส้ม)
3. รอประมาณ 1-2 นาที จนขึ้นเครื่องหมาย **ติ๊กถูกสีเขียว (Success)**
4. คลิกเข้าไปที่ผลการรันครั้งนั้น เลื่อนลงมาที่หัวข้อ **Artifacts**
5. จะพบไฟล์ชื่อ `orbital-strike-1.0.0-mc1.21.1` กดคลิกดาวน์โหลดได้ทันที! จะได้ไฟล์ `.jar` นำไปใส่ในโฟลเดอร์ `.minecraft/mods` ได้เลย!
